# 你好，我是 Xyris

后端工程师，主要做分布式系统和消息队列。

日常的工作是拆解服务边界、设计任务调度，以及处理那些上线之后才会冒出来的问题——请求超时、下游限流、机器故障。我希望系统出问题时能自己扛住，不用每次都找人。

技术栈以 .NET 和 Go 为主，数据库用 MySQL 和 Redis，消息队列是 RabbitMQ，部署在 Docker 和 Linux 上。
